# Tessera public site

A Vite static site published through GitHub Pages at `https://gilsondev.github.io/Tessera/`.

## Develop

```sh
npm ci
npm run dev
npm run build
```

Run these commands in `site/`. Vite's base is `/Tessera/`; verify nested asset and installation links against that path, not only `/`.

The page follows discovery → device preparation → complete Agent installation → integrations → customization. Contributor links are a separate path. Keep compatibility and installation prerequisites close to the corresponding action.

## Assets and version

Brand assets come from `brand/mark.svg`. Product images come from sanitized fixtures under `docs/images/`, imported directly by Vite. Do not copy personal device captures into the site. See the [asset policy](../docs/guides/repository-assets.md).

`public/latest.json` is generated by the Agent release workflow. The main installation action uses `install.command`, which installs both the daemon and app. An app-only ZIP is not a complete installation.

## Verify and publish

Build the site and run the [browser journeys](../docs/guides/testing.md). Check desktop/narrow layouts, version loading, image loading, anchored setup navigation and the complete installer link.

`pages.yml` builds on site/image changes. `agent-release.yml` aligns app/binary versions with its tag, publishes the companion and updates the manifest. Changes to onboarding documentation must ship alongside a compatible companion release; do not deploy new instructions pointing to an older app that lacks the described flow.

Current distribution targets Apple Silicon on macOS 13+. Builds are not notarized; document that beside installation instructions. A public one-click firmware installer and verified Intel binaries are not supplied by the current workflow.
